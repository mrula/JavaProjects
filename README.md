# JavaProjects
This repository contains my personal Java projects.

The user must first install Java.

To run the interactive CV, first compile and then run by writing the following in the command-line:
```
javac InterCV.java
java InterCV.java
```

The interactive CV is still under development. At present, it contains links to my ph.d. thesis and my first-author publications. It also includes a brief introduction to a proposed project in fast-ion tomography. This introduction allows the user to run simple python scripts to display the qualitative difference between Brownian motion and Lévy flights.
